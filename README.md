# Retail Customer Behavior & Sales Intelligence

## Project Overview
An end-to-end data analytics project exploring retail customer
purchasing behavior using Python, MySQL and Power BI Web.

## Business Objective
Identify customer purchasing patterns, product-category performance,
discount usage and customer engagement opportunities.

## Tools
- Python: Pandas, NumPy, Matplotlib and Seaborn
- SQL: MySQL
- BI: Power BI Web
- Version Control: Git and GitHub

## Project Status
In progress.

## Planned Workflow
1. Understand and validate the dataset.
2. Perform data cleaning and exploratory analysis in Python.
3. Load and analyze the data using MySQL.
4. Build an interactive dashboard in Power BI Web.
5. Document business insights and recommendations.

## Repository Structure
- data/raw/: Original dataset
- data/processed/: Cleaned dataset
- notebooks/: Python analysis
- sql/: SQL queries
- powerbi/: Dashboard-related files and notes
- docs/: Project documentation
- images/: Dashboard screenshots

## Dataset
Customer Shopping Behavior dataset.
The data source and its terms of use will be documented
before the final project is published.

## Disclaimer
This project is for educational and portfolio purposes.
